# prithwirajdas.ca — Portfolio Site

Personal portfolio for Prithwiraj Das — Lead Backend / Platform Engineer.

## Hosting Setup

| Layer | Service | Details |
| --- | --- | --- |
| **Domain** | Squarespace | `prithwirajdas.ca` — DNS managed via Squarespace |
| **Hosting** | Netlify | Auto-deploys from this GitHub repo on push to `master` |
| **Source** | GitHub | `prithwirajdas007/prithwirajdas.github.io` |

## How it works

1. Push changes to `master` branch
2. Netlify detects the push and auto-deploys
3. `prithwirajdas.ca` serves the updated site (Squarespace DNS points to Netlify)


## To update

Edit `index.html` directly. No build tools, no dependencies, no npm. Just HTML + CSS + vanilla JS.

```bash
git add .
git commit -m "Update portfolio"
git push
```

Netlify picks it up automatically. Live in ~30 seconds.

## Photo

To change the profile photo, replace `assets/images/profile.jpg` and push. The photo renders as a 160px circle in the hero section.

## Photo gallery

The gallery page is plain HTML and CSS like the rest of the site. The one piece
of tooling is the image pipeline, which resizes full resolution photos into the
WebP derivatives the page loads.

Full resolution originals live **outside** the repo and are never committed.
Put them in `../photo-source/` (a sibling of this repo), or point `PHOTO_SOURCE`
somewhere else.

1. Export the photos, named the way you want them to appear in URLs, for example
   `kolkata-tram-01.jpg`.
2. Add an entry per photo to `photography/photos.meta.json`, keyed by the
   filename without its extension. `alt` is required, `caption` and `order` are
   optional. Photos without an `order` sort last, alphabetically.

   ```json
   {
     "kolkata-tram-01": {
       "alt": "A yellow tram waiting at an empty junction in early morning fog.",
       "caption": "Kolkata, 2024",
       "order": 10
     }
   }
   ```

3. Generate the derivatives and the manifest:

   ```bash
   npm install
   npm run gallery
   ```

4. Review the page, then commit `photography/img/` and `photography/photos.json`
   along with the metadata.

The build refuses to run, and writes nothing, if a photo has no metadata entry,
an entry has no alt text, or an entry names a file that is not there. Rerunning
it regenerates only what changed; `npm run gallery -- --force` rebuilds
everything.

| Role | Width | Format | Quality | Target |
| --- | --- | --- | --- | --- |
| thumb | 900px | WebP | 74 | under 90KB |
| full | 2000px | WebP | 80 | under 400KB |

Photos are auto-rotated to their EXIF orientation and then stripped of all
metadata, GPS included.
